# Описание картинки

Адалинда, Агент и Аутскаут стоят напротив «Студии ночных шалунов».

«Надо исследовать!», — говорит Аутскаут в сторону «Студии». «Надо вступить!», — говорит Агент. Он стоит с заброшенной на плечо лопатой. «Надо поесть!», — говорит Адалинда.

«Студия» расположена в прямоугольном здании. Передняя часть студии изображена в виде плоской волчьей морды с разинутой пастью. На лбу морды написано: «Студия ночных шалунов». Разинутая пасть — дверь в студию. По бокам морды расположены окна.
